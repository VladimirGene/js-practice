1. Создание калькулятора

1.1 Создать класс Calculator. 
   В нём завести статическое свойство OPERATIONS — реестр поддерживаемых калькулятором операций. 
   Далее создаем constructor в нем находим дисплей, создаем переменную с this.error 
   Инициализируем через init()

1.2 Создаем метод init() и делаем подписку на события нажатия кнопки цифр и операций
   Создаем событие нажатия кнопки backspace для удаление выражения с конца по одному элементу

1.3 Создаем метод updateDisplay()  
   Она должна отрисовывать все изменения на дисплее
   Создаем условие если есть оператор то рисуем дислей равен первый операнд + опертор + второй операнд
   Обновляем дисплей

1.4 Создаем метод reset() 
   Она должна обнулять все данные 
   Первый операнд 
   Второй операнд
   Оператор
   Дисплей 

1.5 Метод bindEvents(event) обработчик событий
   обрабатывает событие нажатия на цифры
   Если нажимается цифра должно отрабатывать метод который отвечает за ввод цифр
   Обрабатывает собития нажатия на операторы
      если нажимается опертор вычисления то вызывается метод выбора оператора
      кнопка С удаления всех данных
      кнопка = вызывается метод подсчета 
  
1.6 Создаем метод inputDigit(digit) для ввода цифр 
   Логика Нужно чтобы на дисплее отображалось (пример 12+34)
   первый операнд будет запоминаться когда мы набираем цифру а второй как мы нажмем опертор будет копиться
   Обработать ошибку если дислей равен Error чтобы при выводе сообщения метод прекращал работу(пример: Ошибка12322)
   Если сначало идет 0 то ноль должен заменятся на цифру и потом дописывается вторая цифра
   (пример: 0(нажали 1) -> 1(нажали 2) -> 12 )
   Если оператор не выбрал то число просто выводится на дисплей
   и защиты от числа больше 12 значений и в дисплей добавляем цифру
   Если второй операнд равен нулю делаем замену 0 как указено выше
   Если второй операнд больше 12 выходим
   И последний записываем во второй операнд число
   Обновляем дисплей 

1.7 Создаем метод setOperator(op) выбор оператора
   Делаем защиту "Ошибка" на экране, если сначало 0 и оператор не выбран для зищиты но +0, если опертор уже есть и второй операнд уже есть чтобы не было цепочки 3+4+5 так как у нас существуют только два операнда(currentValue и previousValue) 
   Далее нужно сохранить previousValue из дисплея
   сохранить оператор 
   обнулить currentValue

1.9  Создаем метод calculate() 
   Останавлием метод если оператор не выбран, previousValue пустое значение, currentValue пустое значение и оператор не равен оперторам вычисления(+,-,*,/)

   Переводим в числовые значения previousValue и currentValue
   Обработываем ошибку при деление на ноль
   Считаем результат с помощью static Calculator.OPERATIONS 
   Обрабатывем если результат не число вызывем setError()
   и выводим на дисплей результат вычисления сбрасывая оператор и currentValue  в previousValue сохраняем результат чтобы считать следующую операцию

2 Создаем метод backspace(event)  
   Если это не кнопка backspace выходим из метода
   Если на дисплее ошибка выходим из метода(чтобы не удалять строку "Ошибка" посимвольно)
   Если опертор есть и второе число введенно то начинаем удаление со второго числа и обновляем дисплей
   если оператор введен то опертору присваем null первое значению приставем пустую строку и на дисплее с конца удалем по одному или 0 элементу и обновляем дисплей
   и с дисплея удаляем с конца по одному элементу или 0 
   дисплей.слайс(0,-1) || '0' (Ноль нужен если строка стала пусто то поставится ноль)
   Обновляем дисплей
